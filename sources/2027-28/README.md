# 2027-28 primary sources

⛔ **THIS TREE IS A DIFFERENT STANDARDS YEAR FROM THE ONE BESIDE IT.** Everything under
`sources/<course>/` without a year in the path is **2026-27**. Everything here is
**2027-28** — the revised Tennessee standards taking effect in 2027-28.

**416 standard codes exist in both years and mean something different.** 2027-28 `US.19`
is the Federal Reserve Act; 2026-27 `US.19` is not. 84 of the 94 US codes and 72 of the 74
Grade 8 codes differ. So:

- **Never join the two trees on `standard`.** A code is not a key across years.
- **Never carry a file from one tree to the other** by code. The web-app repo has
  `scripts/carry-forward.mjs` for that, and it works by content category, never by code.
- `GUARDRAIL.md` Rule 4 pins standards to the **2026-27** source of truth. For this tree
  the source of truth is `Trooptoteacher/2027-28-Tn-Social-Studies-Standards`.

## What is here, and what it is not

Each file is the **verbatim text of the page the citation points at**, extracted from the
Library of Congress's own OCR (ALTO) of the printed volume — the page's own words,
including OCR error. It is not a hand transcription and not a scan; the scan is at the
download URL in the citation file beside it.

`<CODE>_<slug>.txt` · the source · `<CODE>_<slug>.txt.citation.md` · its citation,
rights basis, both URLs, and a SHA-256 of the file.

**Every source here is `UNREVIEWED`.** Retrieval is not review: a machine never writes
VERIFIED, and saving a document does not mean a historian has read it. The citation file
says so on every item. Until a named reviewer rules, these support no claim.

## Why reading them matters, in this repo's own history

Six citations were withdrawn on 2026-10-02 **because the documents were saved and read**.
Each was a real, resolvable Library of Congress citation with the correct volume for its
year and a stored 200 — attached to the wrong claim. The Keating-Owen Act of 1916 pointed
at a page about the McKinley souvenir dollar; the Lend-Lease Act at a land survey. Nothing
in the record looked wrong, and no gate could see it, because nothing was on disk to open.

That is what this tree is for. If a source looks odd, open it — the file is right there.
